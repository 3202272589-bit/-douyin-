<h1 align="center">
  Douyin-Vue
</h1>

douyin-vue 是一个仿抖音的移动端短视频项目，可作为 Vue 在移动端的实践参考，能带来接近原生 App 的流畅使用体验。该项目基于最新的 Vue 技术栈搭建，采用 Vue3、Vite5、Pinia 实现开发；数据直接存储在项目本地，同时通过 axios-mock-adapter 库拦截 API 请求，返回本地 JSON 数据，以此模拟真实的后端接口请求流程。
